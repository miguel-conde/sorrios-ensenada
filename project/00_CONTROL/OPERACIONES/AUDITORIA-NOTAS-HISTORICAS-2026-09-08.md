## Refuerzo del procedimiento

Se modifica únicamente `editorial-procedure.md`:

- se introduce la clasificación obligatoria A/B/C/D antes de decidir las Notas históricas;
- A = sin nota necesaria;
- B = Glosario o índice;
- C = Nota histórica puntual;
- D = Diario o futuro Estudio Histórico;
- se limita la investigación externa a candidatos C que la necesiten;
- se obliga a distinguir manuscrito, fuente externa e inferencia editorial;
- el control de calidad debe responder expresamente si se evaluó la necesidad de Nota histórica y no se dejó vacía por defecto.

No se modifica el Manual Editorial v1.6: su criterio sustantivo ya cubre estas actuaciones. No se modifica `SKILL.md`, porque ya remite al procedimiento y duplicar el checkpoint sería innecesario.
