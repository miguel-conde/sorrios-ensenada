# Errata común — topónimo Sorribos

**Fecha:** 18 de septiembre de 2026  
**Alcance:** documentos históricos preservados bajo `project/90_ARCHIVO/`

Las copias históricas conservadas en este directorio pueden contener la lectura `Sorribas` para el topónimo principal del expediente.

La relectura visual completa del manuscrito fija `Sorribos` como forma de 1752. El topónimo aparece cuatro veces en Portada, folio 306r y folio 306v; una aparición de folio 306r presenta la división `Sorri-` / `bos`, que confirma la lectura.

Los archivos históricos no se reescriben, porque preservan estados anteriores del proyecto. Para cualquier uso actual debe aplicarse esta rectificación:

- forma manuscrita de 1752: `Sorribos`;
- forma moderna: `Sorrios`;
- `Sorribas`: lectura paleográfica errónea introducida por el proyecto, no variante documentada de este núcleo de Ordás.

La formulación canónica vigente consta en la Edición Crítica v3.6, el Índice de topónimos y el Estudio Histórico v1.1.
