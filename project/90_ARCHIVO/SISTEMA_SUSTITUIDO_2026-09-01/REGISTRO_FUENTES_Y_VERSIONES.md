# Registro de fuentes y versiones

## Principio de autoridad documental

Solo habrá una versión activa y autoritativa de cada documento. Cuando una versión nueva entre en vigor, la anterior se retirará de las fuentes activas y el cambio se anotará en el Diario Editorial.

Las autoridades se distinguen por ámbito:

1. **Contenido y materialidad del manuscrito:** `sorrios_ensenada_orden_lectura_calidad_original.pdf`.
2. **Método editorial:** Manual Editorial vigente.
3. **Versiones y composición del conjunto activo:** este Registro de fuentes y versiones.
4. **Transcripción canónica y aparato de cada unidad:** edición crítica vigente.
5. **Estado de trabajo, tareas y dudas abiertas:** Diario Editorial.
6. **Datos derivados de unidades validadas:** Glosario e índices.

Si dos documentos entran en conflicto dentro del mismo ámbito, no se resolverá por conjetura: se detendrá el trabajo afectado, se corregirá la fuente normativa o el Registro que corresponda y se dejará constancia en el Diario.

## Procedimiento de sustitución

Cuando se incorpore una versión nueva:

1. se validará el cambio;
2. se actualizará este Registro;
3. se anotará el cambio en el Diario Editorial;
4. se retirará la versión sustituida del contexto activo;
5. se conservará, si procede, fuera del proyecto como archivo histórico;
6. si el cambio afecta al método o al flujo de trabajo, se actualizarán también las instrucciones generales del proyecto.
